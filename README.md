# مِسَار

أداة لمتابعة أوامر الصرف في منصة فنار.

- GitHub يدخل فنار تلقائياً كل ساعة (من الأحد للخميس، من 7 الصبح إلى 9 الليل)، ويقرأ أوامر الصرف.
- ينشر صفحة استعلام: الشركة تكتب **اسمها + رقم الفاتورة + المبلغ**، وتطلع لها حالة أمر الصرف.
- **الخصوصية:** كل فاتورة مشفّرة بمفتاح مأخوذ من الخانات الثلاث. فالشركة ما تشوف إلا فاتورتها، وما تقدر تعرف شيء عن غيرها، ولا أحد يقدر يقرأ ملف البيانات المنشور.

---

## خطوات التشغيل (مرة وحدة)

### 1) إنشاء المستودع
1. من GitHub اضغط **New repository**، وسمّه مثلاً `masar`.
2. ارفع كل ملفات هذا المجلد، ومعها مجلد `.github` (مهم).

> إذا كان المستودع **عام (Public)** فهو آمن: ما فيه كلمات مرور، والبيانات المنشورة مشفّرة.
> إذا تبيه **خاص (Private)** فنشر الصفحة يحتاج اشتراك GitHub Pro.

### 2) إضافة الأسرار
من **Settings → Secrets and variables → Actions → New repository secret** أضف:

| الاسم | القيمة |
|---|---|
| `FANAR_USER` | اسم مستخدم فنار |
| `FANAR_PASS` | كلمة مرور فنار |
| `MASAR_SALT` | نص عشوائي طويل (30 حرف أو أكثر). اكتبه مرة وحدة ولا تغيّره |

### 3) تفعيل الصفحة
من **Settings → Pages** اختر تحت **Source** الخيار: **GitHub Actions**.

### 4) روابط فنار
افتح `config.json` وحط:
- `loginUrl`: رابط صفحة الدخول.
- `ordersUrl`: رابط صفحة أوامر الصرف.

### 5) أول تشغيل (وضع الفحص)
1. من تبويب **Actions** اختر **مسار - تحديث أوامر الصرف**، ثم **Run workflow**.
2. فعّل خيار **وضع الفحص** وشغّل.
3. إذا نجح التشغيل، يطلع لك رابط الصفحة في خطوة **deploy**.
4. إذا فشل، حمّل ملف **masar-debug** من أسفل صفحة التشغيل وأرسله لي.
   الملف فيه شكل صفحات فنار فقط (أسماء الأعمدة والأزرار)، وكل بيانات الفواتير فيه ممسوحة. أعدّل الإعدادات على أساسه.

---

## إذا طلب فنار رمز تحقق
الأداة تفتح **Issue** في المستودع بعنوان «مِسَار يحتاج رمز التحقق»، ويوصلك تنبيه من GitHub.
اكتب الرمز كـ **تعليق** في التذكرة خلال 8 دقائق، والأداة تكمل لحالها وتقفل التذكرة.
فعّل تنبيهات تطبيق GitHub على جوالك عشان يوصلك الطلب.

## تعديلات شائعة في `config.json`
- **`columns`:** أسماء أعمدة جدول فنار. إذا اختلف اسم عمود، أضف الاسم الصحيح للقائمة.
- **`orders.next`:** محدد زر «التالي» إذا كان الجدول على أكثر من صفحة.
- **التوقيت:** عدّل سطر `cron` في `.github/workflows/masar.yml`.

## ملاحظات
- إذا ما انقرأ أي أمر صرف، الأداة ما تحدّث الصفحة، فتبقى آخر بيانات صحيحة.
- GitHub يوقف المهام المجدولة إذا ما صار أي تعديل على المستودع لمدة 60 يوم. إذا وقفت، فعّلها من جديد من تبويب Actions.
- الاسم يتطابق حتى لو اختلفت الهمزات أو التاء المربوطة، أو انكتبت كلمة «شركة» أو «مؤسسة» أو انحذفت.
- رقم الفاتورة يتطابق بغض النظر عن الشرطات والمسافات.
- المبلغ يقبل الفواصل والأرقام العربية.
